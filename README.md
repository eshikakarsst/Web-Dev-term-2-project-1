A modern, interactive web application built with React that allows users to search and discover delicious recipes from around the world.

## 📖 **Project Overview**

Recipe Finder is a user-friendly recipe search application that fetches real-time data from TheMealDB API. Users can search for recipes by ingredients, view detailed cooking instructions, save their favorite recipes, and filter results based on dietary preferences.

---

## ✨ **Features**

### 🔍 **Core Functionality**
- **Search Recipes**: Search for recipes by ingredient name (chicken, pasta, beef, etc.)
- **View Recipe Details**: Click to expand and view ingredients, measurements, and step-by-step instructions
- **Favorite Recipes**: Add recipes to favorites with a simple heart button click
- **Favorites Counter**: Track the number of saved favorite recipes
- **Vegetarian Filter**: Toggle to show only vegetarian recipes
- **Video Tutorials**: Watch YouTube cooking tutorials for selected recipes

### 🎨 **User Interface**
- Clean, modern card-based design
- Responsive grid layout that adapts to all screen sizes
- Smooth animations and transitions
- Color-coded category and cuisine badges
- Hover effects for better interactivity
- Loading spinner during data fetch
- User-friendly error messages
- Empty state guidance when no results found

### 🛠️ **Technical Features**
- Real-time API integration with TheMealDB
- Asynchronous data fetching with error handling
- Multiple state management using React Hooks
- Conditional rendering for different UI states
- Dynamic filtering and search functionality
- Toggle interactions for expandable content
- Immutable state updates following React best practices
